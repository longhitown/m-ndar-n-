# màndarínō

Il cinese per italiani, l'italiano per chi parla cinese. App web offline in un file unico (`dist/index.html`), installabile
come PWA, e APK Android senza Play Store.

- Scarica l'APK: <https://github.com/longhitown/mandarino/releases/latest/download/mandarino.apk>
- Pagina di presentazione: `docs/index.html`, pubblicata con GitHub Pages insieme a `privacy.html` e all'app ([come](LEGGIMI.md#pubblicare-su-github-pages-pagina-di-presentazione--app))
- Documentazione completa (in italiano): **[LEGGIMI.md](LEGGIMI.md)**
- Come sono fatti i moduli: [docs/ARCHITETTURA.md](docs/ARCHITETTURA.md)
- Privacy: [PRIVACY.md](PRIVACY.md) (nessun dato raccolto · 不收集任何数据)
- Prove: `npm install && npm test`
- Vuoi aiutare? Anche senza programmare: [CONTRIBUTING.md](CONTRIBUTING.md) · 不会编程也能参与 · chi ha contribuito: [CONTRIBUTORS.md](CONTRIBUTORS.md)

[![Sostieni il progetto](docs/img/sostieni.svg)](https://ko-fi.com/mandarinoapp)

màndarínō è gratuita, senza pubblicità né account. Una donazione è del tutto libera e non sblocca nulla; chi lo chiede riceve
un sigillo di gratitudine, assegnato a mano ([come funziona](docs/sigilli.md)).
